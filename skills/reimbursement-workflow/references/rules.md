# 规则索引与适用范围

项目由可逐条检查的规则组成。通用规则约束材料真实性、费用对应和交付检查，场景规则补充申请人类别、经费、票据和办理流程的边界。每次只将有依据且适用的条目纳入私人案例的检查矩阵。

## 新需求与冲突

南京大学场景依次检查：身份与路线（001）、事前审批（002）、分阶段材料（003）、时长与学生补助（004）、住宿例外（005）、交通及补助去重（006）、模板与币种（007）、票据时限和打印（008）、支付方式及学生例外（009）。逐项记通过、未通过、待确认或有依据的不适用；不以“没有触发全部场景”为由扩充无关材料。历史“超过 1,000 元截图”不作为学校门槛；按 009 分清单笔支出与单张发票的含等号条件及例外。专项资助另外匹配 `NJU-FUND-*`；不能从境外或某批次规则反推未覆盖情形。

已有场景能覆盖时补充原文件，否则按模板新建场景并登记到此表。规则应写明稳定标识符或可定位条目、适用条件、来源及日期、具体要求、不适用边界、正反例和替代关系。有依据的规则可直接维护；尚无依据的需求记录为待确认。

只有范围匹配且依据成立的条目才应用。较新或更具体不自动意味着可以覆盖旧规则；替代时说明准确范围。个人要求纳入某项费用不代表财务认可。适用依据冲突或影响交付的问题未解决时，不得将材料标为最终版本。

实际执行顺序和最终交付条件统一见[执行流程](workflow.md)，逐条结果写入私人案例的[复核记录](../assets/review.md)。本索引不保存真实票据、个人金额、账户或行程决定。
